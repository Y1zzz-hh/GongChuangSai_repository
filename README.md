# 工创赛协作仓库

华中科技大学（HUST）学生备战 **中国大学生工程实践与创新能力大赛（工创赛）** 的团队协作仓库，参赛方向为 **智能物流搬运**。

## 目录结构

| 目录 | 说明 |
| --- | --- |
| `代码/` | 项目源代码（控制、驱动、算法等） |
| `设计方案/` | 作品设计方案文档 |
| `参考资料/` | 学习与参考资料 |
| `赛事要求与说明/` | 赛事规则、讲解 PPT 等官方说明 |

## 协作规范

- 提交代码前请先拉取最新代码（`git pull`）。
- 提交信息保持简洁清晰，说明本次改动内容。
- 编译产物、日志、临时文件等请勿提交（已通过 `.gitignore` 排除）。
- 大文件与打包产物（如 `.zip`）请勿直接放入仓库。
